# 👋 Jesus Fernández Machín

<sub>🇬🇧 English version: [README.md](./README.md)</sub>

Soy desarrollador de software venezolano, radicado en Santiago de Chile. Me especializo en crear soluciones que simplifican flujos de trabajo complejos e impulsan la innovación. Mi experiencia abarca plataformas SaaS para educación, empresas y comercio electrónico, herramientas internas, integraciones de API y aplicaciones web a medida.

Apuesto por el aprendizaje continuo y disfruto trabajando en equipos colaborativos, buscando siempre aportar valor tanto desde el desarrollo de software como desde la mejora de procesos.
